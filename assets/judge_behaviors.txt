PASS 2 BEHAVIOR CODING
Read the same full public conversation independently of the global-rating output. Apply manual sections E and F, including all decision rules and examples. Label assistant text only. User messages supply context and boundaries, not MITI behavior codes.

1. Identify conversational volleys under E.1 and E.3 (pages 13-16). A volley is uninterrupted assistant speech, allowing merely facilitative user interjections. Usually an assistant message is a volley. If an intervening user message is only facilitative, two assistant messages may belong to one volley; record the exact user ID and a boundary explanation. A short direct answer to a question is substantive, even if the answer is just yes. Do not use a word-list shortcut for this decision.
2. Parse assistant messages into contiguous thought units, not mechanically into sentences. Favor fewer parses when unsure. Retain all assistant text, including uncoded greetings or structure. Every non-whitespace character must appear in exactly one utterance span. Keep Markdown markers, bullets and headings in the exact spans; keep adjacent formatting with its text, or use a separate UNCODED span for standalone formatting. Do not strip or normalize characters. A span must be an exact substring of one assistant message. A thought that requires unusual cross-message treatment should be flagged for review; do not invent or merge text.
3. Assign one code to each thought unit using the manual. Export aliases: GI, PERSUADE, PWP, Q, SR, CR, AF, SEEK, EMPHASIZE, CONFRONT. UNCODED is a storage label for material without a MITI code, not an additional MITI category. Provide the exact quote, occurrence_index, message ID, volley ID, brief rationale and manual section. Apply the manual's within-utterance decision rules, including Persuade with Permission when both persuasion categories apply to the same utterance (E.4.c.1). Do not label a single utterance with multiple codes.
4. Preserve repeated utterance labels for audit. The pipeline, not you, calculates official counts: each code at most once per volley; one reflection category per volley, with CR superseding SR; one Q per volley. If separate utterances in one volley retain both PERSUADE and PWP, add a review note: page 13 permits one persuasion category per volley while E.4.c.1 specifies the same-utterance case. Do not silently choose a new cross-utterance rule or count both in a finalized tally.
5. Do not revise behavior labels to agree with presumed global scores. Preserve every uncertainty and all utterance evidence. Output no totals, ratios or invented compliance scores. Output schema: behavior_output.schema.json.
